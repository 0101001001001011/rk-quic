# rk_quic

QUIC и WebTransport для Dart поверх нативной библиотеки.

**Версия 0.0.1 занимает имя и больше ничего не делает.** Содержимого нет: пакет
существует, чтобы доказать конвейер публикации и матрицу сборки на том, что не
может сломать потребителя. Реализация приедет отдельными версиями.

В Dart своего QUIC нет — оба запроса в SDK закрыты со статусом «не планируется», — поэтому реализация живёт в нативной библиотеке и достаётся через `dart:ffi`. Цель — чтобы процесс на Dart сам отдавал HTTP/3, и браузерный клиент говорил с ним по WebTransport вместо опроса REST.

```dart
import 'package:rk_quic/rk_quic.dart';

void main() {
  print(rkQuicVersion);      // 0.0.1
  print(hasNativeTransport);    // false, пока нативной части нет
}
```
